## Design

### Terms

- **Divergence paragraph**: the I.2.a paragraph that begins "The other three
  queue hooks detect a task as **unlaunched** solely from ..." (lines 298-308
  of the integration worktree's `implement-phase.md` at planning time).
- **Divergence span**: in the whitespace-normalized I.2.a section, the text
  from the start of UNLAUNCHED_SOLELY_FROM_ABSENCE_PHRASE through the end of
  AUTHORITATIVE_SOURCE_PHRASE.
- **Fail-open**: only the Supporting cast definition (on an unexpected state
  a hook exits 0 silently). See IMPLEMENTATION.md Conventions, Terminology.

### 1. Divergence paragraph rewrite (FR1, FR2)

The rewritten paragraph carries, inside the divergence span:

1. **Removal**: the phrase "the hooks are fail-open nets, not authorities" and
   every other wording that calls this behavior fail-open are gone; the
   substring "fail-open" does not occur in the span.
2. **Rationale (FR1 a)**: treating a task that has no journal event at all as
   unlaunched is what detects a missed first launch.
3. **Consequence and bound (FR1 b)**: as a result `queue_stop_guard.py` can
   block the end of the turn (exit 2) naming a task whose `workflow.yaml`
   status is `merged`; this false BLOCK is bounded by the consecutive-block
   cap (3), and once the cap is exceeded the hook emits a warning and lets
   the turn end. This behavior is not called fail-open.
4. **Relationship to I.2.b step 1 (FR2)**: I.2.b step 1's reconcile also
   classifies "no event → unlaunched" without consulting status, and the
   `status != merged` exclusion takes effect as I.2.a's selection-time
   filter (I.2.b re-enters I.2.a). The paragraph must not be readable as "the
   orchestrator always combines `status != merged` at classification time".

Constraints:

- The four already-pinned phrases (UNLAUNCHED_SOLELY_FROM_ABSENCE_PHRASE,
  NARROWER_THAN_ORCHESTRATOR_PHRASE, NO_EQUIVALENT_EXCLUSION_PHRASE,
  AUTHORITATIVE_SOURCE_PHRASE) stay present in whitespace-normalized form
  (NFR2).
- Every new sentence for items 2-4 is placed so that it falls inside the
  divergence span (UNLAUNCHED_SOLELY_FROM_ABSENCE_PHRASE stays before it,
  AUTHORITATIVE_SOURCE_PHRASE stays after it); otherwise the "fail-open"
  absence check would not cover the new text.
- The "does not consult status" statement is limited to the
  no-journal-event classification and is not worded so that it can be
  confused with the failed-and-pending recycled-task-id carve-out (SPEC A7).
- The I.2.a Select line, including its raw literal whose line break
  position is pinned, is not edited (NFR1).
