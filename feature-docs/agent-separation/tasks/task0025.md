## Design

Findings addressed: `bs7`, `bs14`, `bs5` (dispatch half), `bs10` (invocation half), and the stray reference noted inside `bs1`. Read `feature-docs/agent-separation/reviews/round2.yaml` first.

**Citations.** Rule R1's normalization procedure and the validation-layer table now live in the envelope contract, and rule R2 lives in the workflow schema. Both protocols still name the design document as where to resolve them, at the citation lists and at each later mention. An installed plugin has no feature-docs directory, so the named target does not exist at runtime. Repoint every one of those mentions to the shipped documents and keep the design-document section numbers as provenance only — the envelope contract already models the phrasing.

**Prior analysis.** task0024 adds a `prior_analysis` envelope field with `content` and `input_digest`. Populate it on every analyst re-dispatch within a clarification loop, taking the content from the previous round's result and the digest from the input that produced it. State that the field is omitted when the digest no longer matches. The field's name and shape are fixed by task0024; do not vary them.

**Snapshot enumeration.** The whole-tree content hashing is already gone. What remains is that the pre-dispatch snapshot still lists every tracked entry and the comparison lists them again. Keep the head tree as the baseline and enumerate candidates from the porcelain status and the index-versus-working-tree comparison, querying blob identifiers and modes only for those candidates. Deletions, mode changes and file, symlink or absent transitions must remain detectable. The specification and the design document were amended by the orchestrator to match this direction, so the requirement text now agrees.

**Invocations.** The canonical invocation omits the phase-state argument, so the duplicate-patch-identifier check never runs; add it and add the omission to the accompanying list of arguments whose absence silently narrows validation.

**Stray reference.** One create-spec passage names the interim snapshot's key when describing the completed payload, whose key differs. Correct it.
