## Design

**workflow-schema.md** removes the upstream-agent write exception so the orchestrator is the sole writer with no carve-out, documents the phase-state sibling directory alongside the other feature artifacts, adds the normative definition of the completion-commit field together with its applicability to all seven steps and the note that the completion status update is always a separate commit from the artifacts, adds the design-system block with its two fields and three kind values, and states the domains vocabulary SSOT.

**command-execution-protocol.md** describes how the approval gate is expressed as a question packet and names its gate identifier, without restating the packet schema.

**The four templates, the license compatibility reference and the skills registry** currently name the removed agent in their opening lines. Each is retargeted to the worker that now performs that role: the two document templates and the test readme template to the authoring worker, the task plan template to the planner, and the registry and license references to their current readers. Only the header references change; template bodies and structural markers are untouched, because the validator's Markdown parsing depends on the existing structures.

**plan-writing/SKILL.md** gains an explicit statement that its domain descriptions are criteria rather than the vocabulary source, naming the registry as the source.

**design/SKILL.md** is checked against the designer contract change and updated where it describes shared artifact handling that the contract now governs.

**README.md** describes the worker composition, the phase-state artifact, the batch policy source of truth, and the prerequisites: Python 3 with PyYAML for the bundled validator, and the note that some environments need a Python execution permission entry.

**test/README.md** is amended so its no-external-dependency statement is scoped to test code, removing the apparent contradiction with the plugin's runtime dependency while keeping the rule that tests use only the standard library.

**plugin.json** receives a patch-level version bump and a description updated to match the new worker composition.

**Deletion** of the old create-spec agent happens last within this task, after every reference to it has been retargeted.
