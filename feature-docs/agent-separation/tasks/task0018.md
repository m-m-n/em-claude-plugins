# Task Plan: task0018 — batch の fail-closed 順序と Codex 相談手順の実体化

## Goal

Make the batch fallback abort on specification, security, licensing and irreversible decisions before anything can settle them, and give the Codex consultation an executable procedure inside the plugin.

## Requirements

FR15, NFR4

## Scope

### Files to Modify
- `em-workflow/references/question-resolution.md` — hoist the fail-closed classification, write the Codex consultation procedure as substance
- `tests/test_question_resolution_doc.py` — assertions for the new ordering and the procedure

## Design

Findings addressed: `as8` (document half) and the procedure half of `as4`. Full text in `feature-docs/agent-separation/reviews/round1.yaml`; read it first.

**Hoist the classification.** Today the abort rule sits inside the unanswered-behaviour branch at the end of the fallback, so two routes decide first: a Codex suggestion that maps to an existing option settles the gate at step three, and the record-as-TBD branch settles it at step six. The specification-change gate that the policy file deliberately leaves unlisted — precisely so it aborts — is therefore resolvable by an advisor whose output the same document calls untrusted two lines earlier. Move the classification to immediately after confirming the gate is unlisted, and abort for the four categories regardless of the unanswered behaviour, the gate's listing, or whether a mapping exists. Define the classification mechanically: the question's category, an explicit gate identifier list, or an assumption marked irreversible.

**State the enforcement split.** The document should note that a worker-set category or unanswered behaviour cannot be trusted alone, and that the validator cross-checks them — the check itself is task0016's work, so reference it rather than restating the rule.

**Write the Codex procedure.** The concrete loop was deleted along with the old create-spec agent and never landed anywhere: availability probe, the read-only wrapper invocation with the project root, one turn per call with the full prior exchange carried in the prompt, a trajectory judgement after the third turn, a five-turn ceiling, the final decision remaining with Claude, and the output treated as untrusted. Write it here as substance so the two non-packet fallback gates have something to execute.
