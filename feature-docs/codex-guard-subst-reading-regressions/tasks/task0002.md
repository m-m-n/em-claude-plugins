# Task Plan: task0002 — Empty () check skips continuation pairs

## Goal

The empty-parentheses check of a function head inside a double-quoted command substitution treats continuation pairs (a backslash directly followed by a newline) between `(` and `)` like spaces and tabs, so `f(\<NL>)`, `f (\<NL>)`, `function f(\<NL>)` and `f( \<NL>\<NL> )` end a function head and the case statement in the body is read. ### Decision flow of the empty-parentheses check

1. Start at the character after the `(`.
2. While the input has characters left: a space or a tab is skipped; a backslash whose next character is a newline is skipped together with that newline; anything else stops the run.
3. When the run stops at a `)`, the parentheses are empty: the result is the index just after that `)`.
4. Otherwise the parentheses are not empty: the result is the not-found value. This covers the input ending inside the run (after a pair, or at a lone backslash with nothing after it), a backslash followed by any character other than a newline, and any other character.

The check keeps no state, raises nothing for any position of the input and calls no other method.

### Callers and cost

- The callers stay as they are: the `(` read in the head state after the first word of a simple command, after `function`, or after a function name. The three forms `name()`, `function name()` and `function ()` all go through this one check, so all three accept the pairs.
- When the result is the not-found value, the caller reads the `(` as any other `(`, and the characters the check skipped are read once more by the main loop of the skip. Each character is therefore read at most twice, whatever the number of pairs (NFR1: the re-reading is bounded by a constant).

### Documentation (FR8, owned region per IMPLEMENTATION.md)

- The `_empty_parens_end` docstring names spaces, tabs and continuation pairs as what may lie between empty parentheses, states the end-of-input and lone-backslash outcome, and keeps the statements that the extra reading is constant per character and that it calls nothing.
- In rule 6 of the `_skip_substitution` docstring, the sentences that say only blanks lie between the parentheses of `name()` and that emptiness is decided by looking at the blanks once more name the continuation pairs as well. The pinned sentences of the function head rule stay verbatim.
