## Design

### Current reading

In `_skip_substitution`, context `w` is the word list of a zsh
`for name (words)`. The outermost `w` entry is pushed at the `(` that
follows the loop name. A `(` read while `w` is on top pushes another `w`
entry: a nested entry (a glob qualifier as in `*(N)`), whose `)` closes
inside a word. Today both kinds of entry read `#` the same way: a `#` whose
previous character is a space, a tab, a newline, `;`, `&`, `|` or `(`
starts a comment that runs to the next newline, and a comment with no
newline before the input ends raises `_Undecidable`. In `*(#qN)` the `#`
follows the nested `(`, so the chunk is undecidable and the hook gives no
output for a command that launches `python3 -i` after the substitution.

### New reading

| Entry on top | How it is identified | `#` whose previous character is one of the comment-start characters above | Any other `#` |
|---|---|---|---|
| Outermost `w` entry | the entry directly beneath the top of the context stack is not `w` | starts a comment to the next newline; no newline before the end of input stays undecidable (unchanged) | word character (unchanged) |
| Nested `w` entry | the entry directly beneath the top of the context stack is `w` | word character (new) | word character (unchanged) |

- **Identification** (SPEC A1, the SPEC's `stack[-2]`): a `(` read in `w`
  always pushes a `w` entry, and the outermost `w` always sits on an entry
  that is not `w` (a command list, a case item body, and so on). While `w`
  is on top the stack therefore always holds at least two entries.
- **Nested entry, everything else**: every other character keeps its
  present reading. Quoted units, backslash pairs, backticks, `$(`, `$((`
  and `${` are followed as before; `)` closes the nested entry inside a
  word; a `(` opens a deeper nested entry, which is also nested.
- **Outermost entry**: unchanged in every respect (FR2), including the
  TS8 form `for x (# c<newline>a)`.
- **Command lists and case patterns**: their `#` readings are not touched.
- **Cost (NFR1)**: the decision is one constant-time look at the entry
  beneath the top of the stack. No backward scan over the text or the
  stack, no new loop, no recursion, and no new call from the skip into a
  reader (the existing no-recursion and call-structure tests keep
  applying).

### Documentation

The `_skip_substitution` docstring, in its paragraph on the contexts on the
stack, says that in `w` a `#` with those previous characters starts a
comment, "the same start condition as in a command list". Update it to
state that in the word list a `#` starts a comment only in the outermost
entry, and that in a nested entry every `#` is a word character. Update the
inline comment at the context-w branch to say the same. Leave every other
docstring sentence as it is; the existing documentation tests pin many of
them verbatim.

### Byte identity

Make the change once and give the other copy the identical bytes. Both
copies are changed in this task.
