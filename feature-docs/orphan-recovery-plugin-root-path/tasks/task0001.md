# Task Plan: task0001 — Resolve I.2.b orchestrator helper invocations through CLAUDE_PLUGIN_ROOT

## Goal

The three places in `em-workflow/references/implement-phase.md` I.2.b step 1
where the orchestrator itself launches a plugin-bundled helper resolve that
helper under `${CLAUDE_PLUGIN_ROOT}` by citing Step I.0 step 4, the recovery
script runs with `{project_root}` as its working directory, and the
resolution-failure outcome is stated. The two existing test pins follow the
new wording, and a new doc-contract test module detects any return to a
cwd-relative invocation.

## Requirements

FR1, FR2, FR3, FR4, FR5, FR6, FR7, NFR1, NFR2, NFR3, NFR4
