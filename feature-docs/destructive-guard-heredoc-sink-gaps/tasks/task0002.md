# Task Plan: task0002 — Host statement aligned with lex_segments() and escaped quotes in scan_structure()

## Goal

A heredoc's host statement is the statement lex_segments() yields for that
heredoc's operator. A host statement that lacks the heredoc's own operator
makes the destination undetermined, never data. scan_structure() no longer
reads an escaped quote as a quote start. This closes cdb8382d4bbb0b1d
(critical) and 73a1d7b31734dd22.

## Design

### Host-statement boundaries (FR1)

- The host statement for a heredoc operator at position p is exactly the
  lex_segments() statement that contains p.
- There is one definition of statement separators. Prefer taking the host
  statement boundaries directly from lex_segments(). If that is not
  feasible, the boundary computation (_segment_boundaries()) uses the same
  separator recognition as lex_segments(). Two independently maintained
  separator rules must not remain.
- Never separators:
  - redirections: `2>&1`, `>&2`, `&>`, `&>>`, `>|`;
  - escapes: `\;`, `\&`, and a backslash followed by a newline.
- Every separator lex_segments() recognizes stays a separator. Do not keep a
  second list of separators.

### Own-operator check (FR2)

- After a host statement is selected, check that it contains the heredoc's
  own `<<` or `<<-` operator, using the operator position from the heredoc
  recognition result (IMPLEMENTATION.md C3).
- If it does not, the destination is undetermined and the existing fallback
  handles the body (C1). The result is never data.
- The check is a position comparison per heredoc (NFR3).

### Escaped quotes in scan_structure() (FR3)

- Outside quotes, a backslash-escaped single or double quote is a literal
  character, never a quote start (C2).
- The word reading that tells `case` and `esac` apart keeps the backslash
  and the escaped character inside the word. It must not drop the backslash
  and then read the quote as an opener (examples: `echo it\'s`, `echo a\"b`).

### Flow per heredoc

1. Take the operator position from the recognition result.
2. Select the lex_segments() statement containing that position.
3. If that statement does not contain the operator, the result is
   undetermined. Stop.
4. Otherwise hand the statement to command-word resolution (C4), unchanged
   from today.
