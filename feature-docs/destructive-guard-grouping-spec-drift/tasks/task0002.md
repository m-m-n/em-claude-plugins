### tar extract mode (FR6)

- Apply the tar extract-mode rule from IMPLEMENTATION.md exactly.
- Keep the existing recognition of the `-C` / `--directory` value in all four spellings (separate, attached, `=` form, short-option cluster tail). Only the decision whether that value counts as a write target changes: it counts in extract mode, and not in any other mode.
- Mode indicators are read from the tar statement's own arguments. The dashless mode word is considered only when it is the first argument after the command word. A value that belongs to another option (for example the archive name after `-f`) is not a mode indicator.
- The other five families keep their current detection unchanged: rsync last positional argument after value-flag stripping; git clone last positional argument when there are at least two positionals; unzip `-d`; curl `-o` / `--output`; wget `-O` / `--output-document`.
