# Task Plan: task0003 — Reviewer guidance: verify without interactive mode

## Goal

Both `codex-reviewer.md` agents tell the Codex reviewer, in the grounding rules Step 4 builds, never to start an interpreter or shell in interactive mode and to verify with non-interactive forms such as `python3 -c`. Everything else in those files that existing tests pin is unchanged.

## Requirements

FR13, NFR3

## Scope

### Files to Create
- `tests/test_codex_reviewer_interactive_guidance.py` — checks that the new guidance is present in Step 4 of both agents

### Files to Modify
- `em-workflow/agents/codex-reviewer.md` — add the guidance to the Step 4 grounding rules
- `em-review/agents/codex-reviewer.md` — add the same guidance to the Step 4 grounding rules

## Design

- **Where**: the content Step 4 places inside the `<grounding_rules>` block of the prompt it passes to Codex. Add one rule there in each file, with the same meaning in both.
- **What the rule says**:
  - Do not launch an interpreter or shell in interactive mode, or with no program to run. Examples: `python3 -i`, bare `python3`, `node`, `bash -i`.
  - To check something, use one of the three alternatives named in IMPLEMENTATION.md's "Interactive-mode alternatives wording" row: `python3 -c`, a script file, or `python3 - <<EOF`.
- **Language and style**: match the language and bullet style of the existing grounding rules in each file.
- **Must not change**: Step 5's launch line, any heading text or level, the `'timeout of 600000 milliseconds'` text, and anything outside Step 4.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1 (FR13): in `em-workflow/agents/codex-reviewer.md`, the text between the Step 4 heading and the Step 5 heading contains, within the grounding-rules content, a rule that forbids interactive-mode interpreter launches and names `python3 -c` as the way to check.
- [ ] AC-2 (FR13): AC-1 holds for `em-review/agents/codex-reviewer.md`.
- [ ] AC-3 (FR13, NFR3): in both files, the following match the base revision exactly: the list of Markdown headings (text and level, in order), the Step 5 launch line, and the `'timeout of 600000 milliseconds'` text. The existing tests that pin these pass unmodified.
- [ ] AC-4: the new test module checks AC-1 and AC-2. `python3 -m unittest discover -s tests` and `python3 em-workflow/scripts/check-plugin-invariants.py .` both pass.
