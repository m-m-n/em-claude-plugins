# Task Plan: task0002 — Wire develop/SKILL.md to the suppression discipline

## Goal

discipline at every site it owns — `--batch` argument handling, Step A.5,
the design branch, the verify phase, stop condition 5, the stop reports,

interactive behaviour and every existing report element unchanged.

## Test Notes

`tests/test_batch_quiet_output_skill_wiring.py` is a unit-level
document-contract module over SKILL.md's raw text, following
`tests/test_batch_stop_contract_skill_wiring.py`'s form: standard library
only, no import from another test module, constants re-declared locally
(including a locally declared copy of the forbidden literals from
IMPLEMENTATION.md D6(b) plus the marker prefix literal, used for ABSENCE
checks only — this module must not assert what `batch-mode.md` defines, since
task0001's file may not have merged into this worktree yet).

Each new matcher (pointer-site matcher, marker-only-turn matcher, Step A.5
recording matcher, Step C sourcing matcher) carries a negative proof over a
forged section plus a non-vacuity guard. AC-4's and AC-7's non-regression
assertions are pure regression guards over retained wording and are exempt.

TDD-awkward: no runtime behaviour exists; "red" means the assertion fails
against the current SKILL.md text. Write the module and observe each new
assertion fail before editing the document.
