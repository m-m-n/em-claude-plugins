## Goal

A bash / sh / zsh shell reached through an A6 prefix command that carries a
value-taking option (`env -u X`, `nice -n 5`, `timeout -s TERM 2`,
`timeout -k 5 60`, `exec -a name`, `stdbuf -o L`, and their attached and long
forms) is resolved as the executed command, so a loop in its nested text is
denied. An option value is never taken as the executed command word.

### Prefix option table

The reader holds, per prefix command, the options that take a value:

| Prefix | Short options taking a value | Long options taking a value |
|--------|------------------------------|-----------------------------|
| env | `-u`, `-C`, `-S` | `--unset`, `--chdir`, `--split-string` |
| nice | `-n` | `--adjustment` |
| timeout | `-s`, `-k` | `--signal`, `--kill-after` |
| exec | `-a` | none |
| stdbuf | `-i`, `-o`, `-e` | `--input`, `--output`, `--error` |

nohup, setsid, command and time have no entry: their options take no value.

### Skipping one prefix command
For each prefix command in the chain, the words after it are read in order:

- `--` ends that prefix's options. The next word is read as the prefix's
  operand (timeout's duration, env's NAME=value, or the next command word).
- A word `--name=value` whose name is in the table is one complete option.
- A word `--name` whose name is in the table consumes the next word as its
  value.
- A word that starts with a single `-` is read letter by letter. The first
  letter that is in the prefix's short-option column takes a value: the rest
  of the word, when non-empty, is that value (`-uX`, `-n5`, `-sTERM`, `-k5`,
  `-aname`, `-oL`); otherwise the next word is the value. Letters before it
  take no value (`env -iu X`).
- Any other word that starts with `-` takes no value, as today.
- A consumed value is never the command word, even when it starts with `-`
  (`nice -n -5`) or names a shell (`env -u bash`).
- After the options, timeout's duration operand and env's NAME=value operands
  are skipped as today.

Chains keep working: after one prefix is skipped, the next word may be
another prefix (`nice -n 5 timeout -k 5 60 bash -c '...'`). A command that
ends inside an option (a value-taking option with no value word) has no
executed command word and yields no finding for that simple command.

The value of `env -S` is consumed as a value only; its content is not read
as a nested text.

empty. Each command is one CASES row in tests/test_loop_command_guard.py, in
the (expected verdict, label, command) form with the verdict deny or silent.
`LOOP` below stands for `'while false; do :; done'`.

      - `env -uX bash -c LOOP`, `env --unset=X bash -c LOOP`,

        `env -iu X bash -c LOOP`
