# Task Plan: task0001 — Bytecode-free scan-dependencies.py loads in tests

## Goal

Every test module in `tests/` that loads `em-workflow/scripts/scan-dependencies.py`
into the test process does so without writing bytecode, whatever the flag
value it inherits, and a new probe test module proves that behavior for each
of those load sites.

### Loader edit (each row)

Apply IMPLEMENTATION.md C1 inside the loader body and nothing else (C2, C5).
A module that does not yet import the standard-library `sys` module gains
that import. Several of these modules check that their own imports are
standard-library only, and `tests/test_sca_run_scan_plan_units.py` checks
the same for rows 10, 11, 13 and 19 and rejects any `test_` import — the
inline form keeps those checks passing unchanged (IMPLEMENTATION.md D1).

`tests/test_sca_go_replace_direct_deps.py` loads row 9's module by file path
and so reaches row 9's loader at its own import; it needs no edit, because
row 9's edit covers it.

### Probe test module

Responsibilities, following IMPLEMENTATION.md C3 and C4:

1. Hold the 21-row site table above as data: test module file name, loader
   name, path constant name.
2. Once per test class, load each target test module by file path under a
   private name, with the flag forced True during the load and restored
   afterwards; record the recursive listing of `em-workflow/scripts/` first.
3. For each row, each starting value (False, True) and each probe body (one
   that records the flag, one that raises with the flag value in its
   message): write the probe into a fresh test-owned temporary directory,
   set the starting value, replace the row's path constant on the loaded
   target with the probe path for one call, call the loader, and record
   O1–O3; then check O4 on that temporary directory.
4. Report each observation per row (subtests or separate methods), so a
   failure names the row.
5. Check the table has 21 rows and every loader and path constant exists on
   its loaded target; check the `em-workflow/scripts/` listing is unchanged
   after the class's tests.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: For each of the 21 rows, starting from False and from True, a probe body run through the row's loader records the flag as True (O1; FR1, FR3, TS-2).
- [ ] AC-2: For each of the 21 rows, starting from False and from True, the flag equals the starting value after the loader returns normally (O2; FR1, FR3, TS-2).
- [ ] AC-3: For each of the 21 rows, starting from False and from True, a raising probe makes the loader raise that same error with a message showing the flag was True, and the flag equals the starting value afterwards (O3; FR1, TS-2).
- [ ] AC-4: After the probe tests, no probe directory holds `__pycache__`, the recursive listing of `em-workflow/scripts/` equals the one taken before the targets were loaded, the table has exactly 21 rows, and a missing loader or path constant makes the probe test fail (O4; FR1, TS-2).
- [ ] AC-5: Each of the 21 modified modules, and `tests/test_sca_go_replace_direct_deps.py`, run on its own from the repository root starting with no `em-workflow/scripts/__pycache__`, leaves no `__pycache__` under `em-workflow/scripts/`, and its tests pass as they do at the base commit (FR1, FR3, TS-3).
- [ ] AC-6: Every loader keeps its name, parameters, defaults, spec module name and return value; no existing assertion or tested behavior changes; the full suite passes (NFR4, TS-8).
- [ ] AC-7: The task's diff touches only the files listed in Scope, adds only standard-library imports, and never writes, deletes from or patches the process-wide `os.environ` (NFR1, NFR2, NFR3, TS-5, TS-6, TS-7).

## Test Notes

- AC-1 to AC-4 are unit tests in the new probe module. Write it first: before
  the loader edits, AC-1 fails for the starting value False, and O4 fails
  too (the probe's cache appears in the probe's own temporary directory,
  never under `em-workflow/`).
- AC-5 is checked by execution: run each module alone, one after another
  (never in parallel), and look at `em-workflow/scripts/` after each run.
  Before the first run, and after any red-phase run, make sure
  `em-workflow/scripts/__pycache__` is absent in the task worktree (move a
  leftover to the trash). Record the commands and results in the report.
- AC-6 and AC-7 are checked by the full suite plus a review of the diff.
- If a target module needs to be present in the interpreter's module
  registry while its body runs, register it under its private name for the
  duration of that load only.

## Out of Scope

- Any loader of a script other than `scan-dependencies.py`.
- Loads of files under `em-workflow/hooks/` and loads of other test modules.
- Child-process launches of `scan-dependencies.py` (a directly launched main
  script writes no bytecode for itself).
- `tests/test_sca_axis_skill_and_version.py`: its `exec_module` text is a
  string literal fed to its import scanner, not a load.
- A guard that new future load sites are suppressed.
