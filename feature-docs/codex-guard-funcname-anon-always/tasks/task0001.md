## Design

The reading model M1 to M9 in IMPLEMENTATION.md is the contract. This task
places it in the reader as follows.

1. **Start of a word in a command list.** The head state the list held
   before the word decides the reading:
   - function-name state (after the first name): a word with no kind is the
     second name and moves the list to the further-name state (M1); a word
     with a kind is read as today (FR2);
   - further-name state: a standalone `{` or `}` goes to the existing
     command-position reading; any other word is one more name, and the state
     and the command position stay (M1);
   - anonymous-head state: a standalone `{` opens an anonymous body (M2, M3);
     any other word ends the state and is read as today;
   - anonymous-arguments state: the word is an argument; only a standalone
     `}` acts, by M5; the state stays after every other word.
2. **Empty `()`.** The existing empty-parentheses decision also ends a head
   in the further-name state (M1). After `function` with no name, and at a
   command position with no head state, it moves the list to the
   anonymous-head state (M2 forms (b) and (c)). After the first name, after
   further names and after a first word (`name()`), it ends the head as
   today.
3. **`{` that opens a group.** It adds an open-group record for its list,
   marked "anonymous body" for an M2 body and "ordinary" otherwise (M3). In a
   brace-form item body the existing depth still rises.
4. **`}` that closes a group.** It removes the innermost record of its list.
   An anonymous body gives the anonymous-arguments state and no command
   position (M4); an ordinary group gives the group-closed state (M6); no
   record keeps the current reading (A2). In a brace-form item body the
   existing depth still falls.
5. **Lifetimes.** The anonymous-head state survives blanks, continuation
   pairs and newlines (M2). The anonymous-arguments state survives words,
   redirections, heredoc operators, word parentheses and every closing inside
   a word, and ends at a separator or the close of its list (M5). A list that
   closes drops its remaining records (M3).
6. **Re-read (rule 9).** The record kept for each command-position `((`
   holds what M8 needs, and the re-read restores the head state and the open
   records to their values at the `((`.
7. **Comments (FR7, D1).** The module comment before the head-state
   constants lists every head state, the three new ones with their lifetimes.
   Any other comment or docstring outside the `_skip_substitution` docstring
   that the new reading makes false is corrected in the same change. The
   `_skip_substitution` docstring itself is left to task0002.
8. **Placement (D1).** New state declarations go after the existing state
   declarations of the method (after the comment-end position), not right
   under the docstring.
