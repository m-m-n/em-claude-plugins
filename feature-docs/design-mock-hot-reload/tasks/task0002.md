# Task Plan: task0002 — State switch in designer.md's mock rules

## Goal

The Mockups item of designer.md's Design Artifact Rules lets a mock show a single SPEC state through the URL query `?state=<name>`, done by a small inline plain script with an all-states fallback, while the three existing mock-discipline points and every test-pinned phrase of designer.md stay.

## Requirements

FR3, FR4, FR6, NFR2

## Scope

### Files to Create
- `tests/test_designer_mock_state_switch.py` — static tests for the Mockups item of designer.md

### Files to Modify
- `em-workflow/agents/designer.md` — the Mockups item of Design Artifact Rules

## Design

Cross-task decisions referenced from IMPLEMENTATION.md: Shared Components (Mock state switch rule, Mock reload stance), D1, D2, D3, D4, and Conventions (protected wording). This task owns the Mock state switch rule (D1): the contract in IMPLEMENTATION.md Shared Components is what the Mockups item states.

### Mockups item contents after the change

1. **State switch**: the mock reads the query `state`. Only the sections whose `data-state` value equals the query value are shown. The value is used only in a literal equality comparison with each section's `data-state` value; it is never inserted into the document, and no markup, selector or code is composed from it.
2. **Fallback**: with no query, or with a value no section carries, every state section is shown side by side as before. Nothing is hidden unless at least one section matches.
3. **Script allowance**: the wording that rules out scripts in a mock (if present) is narrowed so that one small inline plain JavaScript is allowed, for the state switch only. "no JS frameworks" stays, no external requests stays, inline CSS stays.
4. **Reload stance**: the mock file holds no reload code; a browser update on edit is the dev server's job and is not part of the file (Mock reload stance).
5. **Kept points**: a self-contained single file (inline CSS, no external requests, no JS frameworks), tokens embedded as CSS custom properties, and every state that SPEC names.

### Constraints

- Every phrase `tests/test_refitted_worker_agents.py` pins stays unchanged.
- The change set of this task contains neither `em-workflow/.claude-plugin/plugin.json` nor `.claude-plugin/marketplace.json`.
