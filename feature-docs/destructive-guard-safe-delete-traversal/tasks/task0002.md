# Task Plan: task0002 — Raise the em-workflow plugin version

## Goal

The shipped em-workflow plugin version is raised to the value pinned for this
feature in both manifests, so the installed cache picks up the guard change
instead of serving the previous copy.

## Requirements

FR9

## Scope

### Files to Create

(none — this task only modifies existing files)

### Files to Modify

- `em-workflow/.claude-plugin/plugin.json` — the plugin's own version field.
- `.claude-plugin/marketplace.json` — the version field of the em-workflow
  entry in the plugins list.

## Design

The value and the ownership rule are pinned feature-wide in IMPLEMENTATION.md
(decision D2 and the "Plugin version pair" contract): both manifests move from
0.1.72 to 0.1.73, a patch increment for a behaviour fix.

Only the version field changes in each file. The em-review entry in the
marketplace manifest is a neighbour in the same file and must keep its current
value — the edit targets the em-workflow entry, not every version field in the
document. Both files stay valid JSON with their existing formatting and key
order.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: The plugin manifest's version field reads 0.1.73.
- [ ] AC-2: The em-workflow entry of the marketplace manifest reads 0.1.73 —
      the identical literal value as AC-1.
- [ ] AC-3: The em-review entry of the marketplace manifest keeps its
      pre-existing version value, and no other field of either file changes.
- [ ] AC-4: Both files parse as valid JSON.

## Test Notes

- This task has no runtime behaviour, so its criteria are checked by reading the
  two files back rather than by a new test: parse each file and compare the two
  version values for equality with the pinned literal, and confirm the
  neighbouring plugin entry is untouched.
- The guard's expectation suite is unaffected by this task; it neither needs to
  be extended nor is it evidence for these criteria.

## Out of Scope

- The guard hook and its case table — they belong to task0001.
- Regenerating, reformatting or reordering either manifest.
- Any other plugin's version.
- Publishing, cache installation, or restarting Claude Code to pick the version
  up (a human action reported at completion, not a code change).
