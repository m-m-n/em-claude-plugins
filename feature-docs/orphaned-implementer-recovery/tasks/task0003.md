# Task Plan: task0003 — Orphaned-`launched` detection and recovery entry point

## Goal

A single entry point the I.2.b reconcile step invokes per candidate task,
which either proves the launching session is gone and converts the task
through the journal helper, or leaves everything untouched and reports
exactly why.

## Requirements

FR2, FR5, FR6, NFR1, NFR4, NFR5

## Scope

### Files to Create

- `em-workflow/scripts/recover-orphaned-task.py` — the decision entry point
  (IMPLEMENTATION.md SC3).
- `tests/test_recover_orphaned_task.py` — unit coverage for the evidence
  pipeline, the residual degradations, path containment, the directory
  derivation, and the current-session resolution.

### Files to Modify

None.

## Design

Implement SC3's contract exactly as pinned in IMPLEMENTATION.md. This task
owns the wiring to the journal-write layer (D6): the journal helper is
invoked as a child process at a path defaulting to the sibling
`journal-append-failed.py`, overridable through `--journal-helper` for
testing. This script never writes the journal itself.

**Evidence pipeline, in fixed order.** Each step's failure ends the run with
`residual` and its SC6 reason code, no write and no helper invocation:

1. The agent index holds an entry for the task — else `no-agent-entry`.
2. That entry carries a session identity — else `no-session-id`.
3. The identity passes SC5's validation rule — else `invalid-session-id`.
   The value is not interpolated into any path before this step passes.
4. The current session's identity and start time resolve per D2 — else
   `current-session-unknown`.
5. The recorded identity differs from the current one — else `same-session`.
6. The transcripts directory resolves per D1 and exists — else
   `transcripts-dir-missing`; the assembled transcript path is confirmed to
   resolve inside it (and, under the default derivation, under
   `~/.claude/projects/`) before anything is opened.
7. The transcript yields at least one usable timestamp — else
   `transcript-unreadable`.
8. Its newest usable timestamp is strictly older than the current session's
   start (D3) — else `transcript-active`.

**Journal pre-check.** The task's final event in the journal must be
`launched`. An already-terminal final event ends the run as
`noop_terminal`; anything else is `journal-not-launched` (Residual). The
authoritative check is still SC2's in-lock replay — this one exists to avoid
a pointless child-process invocation, not to replace it.

**On proof.** Invoke the journal helper exactly once with the task
identifier and reason `orphaned`, and propagate its outcome into this
script's own outcome. A helper failure is reported as a non-zero exit; it is
never reported as `recovered`.

**Candidate conditions this script does not re-implement.** Whether the task
worktree and task branch exist, and whether the Agent index resolves a live
agent, remain the orchestrator's existing I.2.b checks. This script assumes
its caller established them.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: With the proven fixture — an agent index entry carrying a
      format-valid identity different from the current session, a transcript
      for that session whose newest activity is strictly older than the
      supplied current-session start, and a journal whose final event for the
      task is `launched` — the invocation reports `recovered` and invokes the
      journal helper exactly once with the task identifier and reason
      `orphaned` (verified against an injected stub implementing SC2's
      outcome contract).
- [ ] AC-2: Each unproven case — identity absent, identity equal to the
      current session, transcript unreadable, and transcript carrying
      activity at or after the current-session start — reports `residual`
      with its distinct SC6 reason code, leaves the journal byte-identical,
      and does not invoke the helper (TS-3).
- [ ] AC-3: An identity failing SC5's rule (path separator, dot segment,
      empty, over-length) reports `residual` with `invalid-session-id`,
      causes no file outside the resolved transcripts directory to be
      opened, leaves the journal byte-identical, and does not invoke the
      helper (TS-5, TS-9).
- [ ] AC-4: The D1 derivation maps a known absolute working directory to the
      expected directory name, and `--transcripts-dir` replaces the
      derivation entirely, so no test resolves a path under the real
      `~/.claude`.
- [ ] AC-5: Current-session resolution follows D2 — an explicit id and start
      pair takes precedence; otherwise the marker scan resolves both the
      identity and the start from the matching transcript; when neither
      resolves, the outcome is `residual` with `current-session-unknown`.
- [ ] AC-6: A journal whose final event for the task is already terminal
      yields `noop_terminal` with no helper invocation and no write.
- [ ] AC-7: With no `--journal-helper` override, the helper path resolves to
      the sibling `journal-append-failed.py`; outcome reporting matches SC3;
      and no non-zero exit path leaves the journal modified.

## Test Notes

- Every fixture is built inside a temporary directory: a worktree root
  holding a journal file and an agent index file, plus a transcripts
  directory injected through `--transcripts-dir`. Real `~/.claude` state is
  never read or written (NFR5), and only the standard library is imported
  (NFR4).
- The injected stub helper records its invocation (task identifier, reason,
  invocation count) and emits SC2's outcome JSON, which keeps this task
  verifiable inside its own worktree. The real pairing with
  `journal-append-failed.py` is TS-1, verified in the verify phase.
- AC-3's "nothing outside the directory is opened" is best asserted
  positively: place a decoy file outside the injected transcripts directory
  that the malformed identity would reach if containment were missing, and
  assert both the reason code and the decoy's untouched state.
- The D1 derivation and the SC5 validation rule are pure functions; test
  them directly with table-driven cases in addition to the end-to-end
  invocations, so a containment regression is localised quickly.
- Keep timestamp fixtures explicit about their instants (including a case
  differing by less than a second across the boundary) so the strict
  ordering in D3 is actually pinned.

## Out of Scope

- The journal write discipline itself — task0002 owns it, and this task
  depends only on SC2's pinned contract.
- Candidate detection: worktree and branch existence, and live-agent
  resolution, stay with the orchestrator's existing I.2.b checks.
- Any change to the agent index writer (task0001 owns it).
- Documentation updates and the plugin version bump (task0004 owns both).
- Widening the reason set, or writing any journal event directly.
