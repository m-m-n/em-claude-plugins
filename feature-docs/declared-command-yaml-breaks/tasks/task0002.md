## Design

### Content to append (the same two points in both files)

1. `declared_commands` puts into the declared set, in addition to `trim_blanks(value)`, the value with every leading and trailing U+0020, U+0009, U+0085, U+2028 and U+2029 removed, when that result is not empty. The definition is IMPLEMENTATION.md Shared Components, "Declared-set end-stripped form"; the appended text names the five characters explicitly, because readers of approval-unicode-whitespace do not have this feature's requirement IDs.
2. Mismatches produced by YAML escape notation, by block scalars, and by characters inside the value are out of scope; such invocations reach the normal permission prompt (IMPLEMENTATION.md Shared Components, "Out-of-scope mismatches").

Nothing beyond these two points is appended.

### Placement and form

- SPEC.md: the text goes with the FR8 entry, either as new lines directly under it or at the end of it.
- THREAT-MODEL.md: the text goes with TM-5. If TM-5 sits in a table row, prefer a note on new lines directly after that table that names TM-5, rather than editing the row.
- Prefer new lines over changes to existing lines. Where a line has to be extended, existing characters stay as they are and the new text follows them.
- Write the text in the language of the surrounding section.
- The appended text adds no heading and no new `TB-n` or `TM-n` identifier, and leaves THREAT-MODEL.md's verdict unchanged.
- The appended text carries no absolute path under a home directory and no Notion URL.
