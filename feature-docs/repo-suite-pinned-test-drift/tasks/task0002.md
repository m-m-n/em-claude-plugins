## Design

SKILL.md is a shared artifact that task0001 edits in parallel, at line 106 only. Its contract is pinned in IMPLEMENTATION.md Shared Components ("develop SKILL.md (artifact)"). Every check in this task must pass on SKILL.md both with and without task0001's edit. None of the checks below reads line 106.

**FR1: argument-hint pin (`tests/test_develop_once_option.py`)**

- ARGUMENT_HINT_LINE becomes the current line 4 of `em-workflow/skills/develop/SKILL.md`, character for character: `argument-hint: "[feature-path] [--report-only] [--batch] [--once] [--pr] [task-description]"`.
- The token check in test_argument_hint_line_includes_once_and_retains_existing_tokens also requires `--pr`. Every token it already requires stays required.

**FR2: Step C batch auto-select wording (`tests/test_step_c_verify_failed_default.py`)**

- BATCH_AUTO_SELECT_PHRASE becomes the current batch sentence of Step C item 1 (SPEC FR2 quotes it verbatim): ``batch: `--pr` 未指定なら質問せず自動で「ブランチを残す」を選ぶ。マージ・push・PR 作成のいずれも行わない``.
- The comparison stays as it is: both sides go through the module's existing `_strip_ws` whitespace removal.

**FR3: Non-packet gates reference (`tests/test_step_c_verify_failed_default.py`, D4)**

- In test_batch_non_packet_gates_reference_present, the check for the reference to batch-mode.md's Non-packet gates table changes. The expected phrase is written as it appears in SKILL.md. Both it and the scanned SKILL.md text go through `_strip_ws`, and the check tests the first as a substring of the second. The scanned text keeps whatever scope the test uses today. This is needed because the reference wraps across lines 918-919.
- The `develop.completion` check in the same test is kept unchanged.

**Matcher / loader separation and negative proofs (NFR3)**

Following IMPLEMENTATION.md Conventions, the three changed checks become matchers over given text. The live tests call them with the text loaded from SKILL.md. Negative-proof tests call them with forged in-memory text:

- A forged argument-hint line equal to the current one but without `--pr` is rejected.
- Forged Step C text that holds only the phrase BATCH_AUTO_SELECT_PHRASE had before this change, and not the current phrase, is rejected.
- Forged text where the Non-packet gates reference wraps across a line break with indentation is accepted.
- Forged text where that reference is missing, or has one word altered, is rejected.
