# Task Plan: task0002 — Document the any-component symlink rule and the exit-2 capability case

## Goal

The script's docstring, the `OPEN_FLAGS` comment and the "Calculation" section
of `em-workflow/references/artifact-digest.md` all say two things: a symlink at
any component of a path yields `not_a_regular_file`, and exit code 2 also
covers a platform that lacks the capabilities the walk needs.

## Requirements

FR7, NFR3, NFR4

## Scope

### Files to Create
No files are created.

### Files to Modify
- `em-workflow/scripts/artifact-digest.py` — the module docstring and the
  comment attached to `OPEN_FLAGS`, and nothing else in the file
  (IMPLEMENTATION.md D1, D2).
- `em-workflow/references/artifact-digest.md` — the "Calculation" section only.
- `tests/test_artifact_digest_docs.py` — new document assertions. Existing test
  methods stay unchanged.

## Design

The text describes the CLI contract pinned in IMPLEMENTATION.md
("CLI contract"). This task changes no behaviour.

### Module docstring
- `not_a_regular_file` line in the error-token list: add that a path any of
  whose components is a symlink gets this token. The existing final-element
  kinds stay.
- "Entry kinds" paragraph: state that no component of the path is followed as
  a symlink, and remove any wording that limits the no-follow rule to the final
  component.
- Exit code 2 line: add the case of a platform that lacks descriptor-relative
  open, the no-follow open flag or the directory-only open flag. In that case
  no array is printed.

### Comment attached to `OPEN_FLAGS`
- State that this set opens the final element without following a symlink, and
  that no component of the path is followed: intermediate components are
  opened as directories, also without following. Nothing in the comment may
  imply that only the final component is protected.

### "Calculation" section of artifact-digest.md
- `not_a_regular_file` item: add the FR7 wording "or a path any of whose
  components is a symlink", word for word.
- Exit code `2` item: add the case of a platform that lacks the needed
  capabilities.
- No other section repeats this wording, including the sections that describe
  where digests are computed at dispatch time (FR7).

### Document tests
- Slice the reference text by its "Calculation" heading, and slice the
  docstring's `not_a_regular_file` line, "Entry kinds" paragraph and exit code
  2 line. Then assert presence and absence of wording on those slices (TS-7).
- Read the docstring and the comment from the script's file text. These tests
  must not depend on the new walk behaviour, which is not present in this
  task's worktree (D1).
