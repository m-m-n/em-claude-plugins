# Task Plan: task0001 — Walk path components without following symlinks

## Goal

`em-workflow/scripts/artifact-digest.py` walks each path argument one component
at a time and never follows a symlink at any component, so a symlink anywhere
in the path yields `not_a_regular_file` and no digest. Results for paths
without symlinks stay as they are, and the script refuses to run (exit 2)
where the walk cannot be done.

## Requirements

FR1, FR2, FR3, FR4, FR5, FR6, NFR1, NFR2, NFR3, NFR4

## Scope

### Files to Create
No files are created.

### Files to Modify
- `em-workflow/scripts/artifact-digest.py` — add the start-up capability check
  (FR6). Replace the per-argument open, which today refuses a symlink only at
  the final component, with the component walk described below. Leave the
  module docstring and the comment attached to `OPEN_FLAGS` untouched

- `tests/test_artifact_digest_script.py` — add behaviour tests for the

## Design

This task implements the CLI contract pinned in IMPLEMENTATION.md
("CLI contract"): invocation, output shape, error tokens and exit codes. It
follows that document's fail-closed convention.

### Start-up capability check (FR6)
- Runs once, before any argument is processed.
- Checks three capabilities: descriptor-relative open (an open that accepts a
  directory descriptor as its base), the no-follow open flag, and the
  directory-only open flag.
- If any of them is missing: write one stderr message that names each missing
  capability, print nothing on stdout, and exit 2. There is no fallback path.
- Starting the script must not raise when either flag is absent, and that
  includes module-level definitions such as `OPEN_FLAGS`. This check is the
  only place that reports the absence. The tests remove the flags first and
  then run the script in-process.

### Per-argument walk
1. An empty argument → `missing`.
2. Choose the base: `/` for an absolute argument, the current directory for a
   relative one.
3. Split the argument on `/` and drop empty and `.` segments. If the argument
   ends in `/`, or its last segment is `.`, mark the last remaining component
   *directory-required*. This keeps `a.md/.` at `missing`, as it is today.
4. If no component is left (`.`, `/`, `./`), the argument names its base
   directory → `not_a_regular_file`.
5. Open each intermediate component, and a directory-required final
   component, relative to the current directory descriptor with FR1's
   directory flag set (directory-only, no-follow, non-blocking,
   close-on-exec). When the open succeeds, the new descriptor becomes the
   current directory descriptor and the previous one is closed. `..` is opened
   the same way, so it climbs the real directory structure (FR4, A4).
6. If that open fails with ENOTDIR or ELOOP, inspect the component's kind
   relative to the same parent descriptor, without following a symlink (FR3
   business rule):
   - a symlink (to a directory, to a file, dangling or looping) →
     `not_a_regular_file`;
   - something that exists but is neither a directory nor a symlink (a regular
     file, FIFO, device or socket) → `missing`;
   - nothing there any more → `missing`;
   - the inspection itself fails, or reports a directory because the
     component was swapped again → an error token, never a digest.
   Any other open failure goes through the script's existing failure-to-token
   mapping: absent → `missing`, permission or I/O error → `unreadable`.
7. A directory-required final component that opens as a directory →
   `not_a_regular_file` (`dir/`). When it fails to open, step 6 applies:
   `a.md/` → `missing`, `link-to-dir/` → `not_a_regular_file`.
8. Open any other final component relative to the last directory descriptor
   with `OPEN_FLAGS`, FR1's final-element set (read-only, no-follow,
   non-blocking, close-on-exec). The regular-file judgement is made on that
   descriptor (FR5). A non-regular file → `not_a_regular_file`. A regular file
   is read in bounded chunks and hashed (NFR1). Existing final-element
   behaviour does not change: a symlink, directory, FIFO, device or socket
   still gives `not_a_regular_file`, and the existing final-element swap
   handling stays.
9. Before the next argument starts, close every directory descriptor opened
   for this argument, on success and on every failure branch (NFR2).
10. Output and the exit code follow the shared CLI contract.

No step resolves the argument as one whole string, and success is never
decided that way (FR1).

### Constants
- `OPEN_FLAGS` keeps its name and its role as the final-element flag set
  (IMPLEMENTATION.md D2). This task owns its value but not its comment.
- If this task names the intermediate-directory flag set, that set is a
  separate constant with its own comment, written by this task.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1 (TM-1; FR1, FR2; SPEC AC1; TS-1): Set up a temp tree with
  `outside/a.md` and a link `work/link` pointing to `../outside`. Running the
  script from `work` with `link/a.md` prints exactly one entry, with `path`
  `link/a.md`, `sha256` null and `error` `not_a_regular_file`, and exits 1.
  The digest of `outside/a.md` does not appear anywhere on stdout.
- [ ] AC-2 (TM-1; FR2; SPEC AC2, AC3; TS-2, TS-3): Each of the following yields
  `not_a_regular_file`, `sha256` null and exit 1, and the link target's digest
  does not appear on stdout:
  - an absolute argument through the directory link, built from the fully
    resolved temp root;
  - `sub/link/x/a.md`;
  - a dangling intermediate link, `dangling/a.md`;
  - `file-link/x`, where `file-link` points to a regular file;
  - `loop-a/x`, where `loop-a` is part of a link loop.

  A regular file passed in the same invocation still gets its digest. On a
  system where `/proc/self` is a symlink and `/etc/hosts` exists, passing
  `/proc/self/root/etc/hosts` and `/etc/hosts` in one invocation gives entry 0
  `not_a_regular_file`, entry 1 a digest, and exit 1. This case is skipped on
  other systems.
- [ ] AC-3 (TM-4; FR3, FR4, FR5; SPEC AC4; TS-4, TS-8): These results hold:
  - `plain.md/child.md`, `no-such-dir/a.md`, the empty argument, `a.md/` and
    `a.md/.` → `missing`;
  - `dir/` and `link-to-dir/` → `not_a_regular_file`;
  - an intermediate FIFO `fifo/x` → `missing`, and a final FIFO →
    `not_a_regular_file`, both returned within a bounded time (the test fails
    rather than hangs);
  - `sub/../sub/a.md`, `sub//a.md`, `./sub/a.md` and the fully resolved
    absolute path of `sub/a.md` get the same digest as `sub/a.md`;
  - an intermediate directory with mode 0o000 → `unreadable` (skipped when
    running as root, or when access succeeds anyway).

  The existing error-token tests pass without modification.
- [ ] AC-4 (TM-2; FR5; SPEC AC5; TS-5): Use a test driver that steps in on
  every directory-only open made relative to a directory descriptor. It first
  replaces the named directory with a symlink to an outside directory that
  holds a file of the same name, then performs the real open. The argument
  yields `not_a_regular_file`, and the outside file's digest does not appear on
  stdout. The existing final-element swap test passes without modification.
- [ ] AC-5 (TM-3; FR6; SPEC AC6; TS-6): Run three subTests: one with the
  no-follow flag removed from the os module, one with the directory-only flag
  removed, and one with descriptor-relative open support withdrawn. In each,
  running the script in-process with a valid regular-file argument exits 2,
  stdout is empty, and stderr holds a message that names the withdrawn
  capability and contains no traceback. Each subTest restores the os module
  afterwards.
- [ ] AC-6 (NFR2; TS-9): Run one in-process invocation whose arguments produce
  a digest, `missing`, `unreadable`, `not_a_regular_file` through an
  intermediate symlink, and a directory-required failure. After the run, no
  descriptor opened during it is still open.
- [ ] AC-7 (NFR1, NFR3, NFR4; SPEC AC8; TS-10, TS-11):
  `python3 -m unittest discover -s tests` passes, including the existing
  standard-library-only / no-child-process test. No existing test method in
  `tests/test_artifact_digest_script.py` is modified. The module docstring and
  the comment attached to `OPEN_FLAGS` are byte-identical to the base. No
  plugin version field is edited.

## Test Notes

- Run the script against temp trees the way `tests/test_artifact_digest_script.py`
  already does, and reuse that file's existing final-element swap driver as
  the model for the AC-4 driver.
- Build absolute-path cases (AC-2, AC-3) from the fully resolved temp root.
  Where the temp root sits under a symlink (A1), an unresolved absolute path
  would yield `not_a_regular_file` for the wrong reason.
- AC-5 has to run in-process (TS-6), because the flags are removed from the
  same interpreter that runs the script. Restore the removed attributes, and
  the descriptor-relative support set, in cleanup that runs even when the
  subTest fails.
- AC-3's FIFO cases run under a bounded timeout. Skip them where FIFOs cannot
  be created. Restore the 0o000 directory's permissions in cleanup so that the
  temp tree can be removed.
- AC-6: observe descriptors in-process. Either record the descriptors the walk
  opens and check that each was closed, or compare the process's set of open
  descriptors before and after the run.
- A directory-only, no-follow open of a symlink fails with ENOTDIR on Linux and
  can fail with ELOOP on other platforms. Assert the error token, not the
  errno.
